LAB-01 – Task 02: Diagonal Matrix

Description

This program reads a square matrix of a user-defined size and checks whether it is a diagonal matrix. A matrix is diagonal when every element outside the main diagonal is zero. Values on the main diagonal may be zero or non-zero.


Example

Input


Enter the size of the square matrix: 3
Enter the matrix elements row by row:
1 0 0
0 4 0
0 0 -2

Output


The matrix is a diagonal matrix.

Compile and run

g++ main.cpp -o diagonal_matrix
./diagonal_matrix
