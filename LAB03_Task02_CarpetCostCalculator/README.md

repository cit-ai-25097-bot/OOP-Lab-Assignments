LAB-03 – Task 02: Carpet Cost Calculator

Description

This program estimates carpet costs for multiple rectangular rooms. It uses the FeetInches and RoomDimension structures, stores room dimensions in a dynamically sized vector, and provides a menu to display each room's cost or the total cost for the house.


Calculation


Convert feet and inches into feet: feet + inches / 12.0.

Calculate floor area: length × width.

Calculate carpet cost: area × price per square foot.


The user enters the carpet price per square foot. The example in the lab uses Rs. 18.


Menu


Option 1: display the cost for each room.

Option 2: display the total cost for all rooms.

Option 0: exit.


Implementation note

The prototype printed in the PDF, int computeTheCarpetingCost(const int& RoomDimension);, does not match the provided structures or the required calculation. This implementation uses double computeTheCarpetingCost(const RoomDimension&, double) so it can accept a room and a carpet rate and preserve decimal costs.


Compile and run

g++ main.cpp -o carpet_calculator
./carpet_calculator
